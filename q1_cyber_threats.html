Common Cyber Threats

Threat Description Prevention
Phishing Fake emails or websites tricking users into sharing passwords or OTPs. Verify sender address, check URLs, and enable 2FA.
Malware Malicious software like viruses or trojans that harm or spy on systems. Use updated antivirus and avoid untrusted downloads.
Ransomware Encrypts user files and demands payment for the decryption key. Maintain regular offline backups and patch OS regularly.
SQL Injection Inserting malicious SQL code into input fields to access databases. Use parameterized queries / prepared statements.
Cross-Site Scripting (XSS) Injecting malicious JavaScript into web pages viewed by other users. Escape output, sanitize input, and use CSP headers.
